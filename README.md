# Roselle

A soft, floral-inspired personal homepage built with HTML and Tailwind CSS.

## Preview

Open `index.html` in a browser, or start a local server from the project directory:

```powershell
python -m http.server 5500
```

Then visit [http://localhost:5500](http://localhost:5500).

Tailwind CSS is loaded from its CDN, and the page uses remote images.
